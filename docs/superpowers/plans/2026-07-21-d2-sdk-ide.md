**Goal:** 在 D1 的 V14 版本化 Agent API 稳定后，交付由协议 schema 生成类型的 TypeScript/Python SDK，以及一个可断线恢复的 VS Code 扩展，覆盖 thread start/resume、turn run/stream/cancel、IDE 上下文注入与 diff 展示。

**Architecture:** SDK 不直接暴露当前 `internal/proto.ClientFrame`/`ServerFrame`，而是依赖 D1 发布的版本化、camelCase、thread/turn/item 资源契约；D2 先用一份明确标记为 provisional 的 v1 schema 起稿，所有路径、字段、事件和序列化均集中在生成层/transport 层，D1 契约落定后只替换 schema 与适配表。TS SDK 先实现 HTTP + SSE/WS 事件传输，再以同一份 schema 生成 Python 模型和异步 client；VS Code 扩展只依赖 TS SDK，通过 event cursor 和去重集合恢复断线，不把编辑器上下文伪装成用户指令。

**Tech Stack:** TypeScript 5.x · Node.js 20+ `fetch`/`ReadableStream` · `ws` · `json-schema-to-typescript` · Vitest · Python 3.11+ · `httpx` · `websockets` · Pydantic v2 · pytest · VS Code Extension API · `@vscode/test-electron`。

## 施工前约束与现状基线

- 本计划只覆盖新建 `sdk/`、`ide/vscode/`、契约 schema/fixture 和对应 JS/Python 测试；不在 D2 直接改 `*.go`。
- 本计划当前只写到 `docs/superpowers/plans/2026-07-21-d2-sdk-ide.md`，实施阶段才执行下方 Node/Python 命令；本次不运行 `go build`、`go test` 或任何构建/测试。
- 真实现状必须被视为迁移输入，而不是 V15 的最终公共 API：
  - `internal/api/http/chat.go` 的 SSE 是 `POST /api/v1/chat`，请求可带 `message`/`messages`、`model`、`thinking`、`output_schema`，事件使用 `ServerFrame.SSEEvent()`。
  - `internal/api/http/ws.go` 的 WS 是 `GET /api/v1/chat/ws`，客户端发 `user_message`、`cancel` 和控制帧，服务端发 `agent_chunk`、`thinking`、`tool_call`、`tool_result`、`status`、`done` 等帧；WS 由服务端持有历史，SSE 由客户端回放历史。
  - `internal/api/http/session.go` 目前只有 `/api/v1/sessions` 列表与读取接口；当前并不存在 V14 所需的 thread/turn/item 资源路由。
  - `internal/proto/frame.go` 是当前 SSE/WS 共享帧词汇和 snake_case 线上字段的依据；D1 必须提供把这些帧映射到 V14 `item`/`turn` 资源的边界，SDK 不复制一份内部帧协议。
  - 当前 HTTP 鉴权对非 loopback 请求要求 `Authorization: Bearer <token>`；SDK 只能通过 header 注入 token，不能把 token 放 URL 或日志。
- **D1 硬依赖：** V15/O12 依赖 `[V14]`。D1 尚未敲定版本化 API，所以本计划中的 `/api/v1/threads...` 路径、字段名、事件名和 cursor 规则均是“假设的 v1 契约”，不是对现有 Go 路由的断言。D1 完成后必须用 schema diff 与 contract matrix 替换/确认它们；若 D1 选择 JSON-RPC 命名，只需在 SDK transport 的 path/method adapter 层变更，不能把 RPC 名称散落到 SDK 与 IDE。
- **版本策略：** 初版客户端只接受 `v1`/`v1.x` 的向后兼容 minor 版本；未知 major、缺失版本、非法 event cursor 均显式报错。响应中的新增字段和未知事件字段必须忽略而不崩溃；未知事件类型记录为 `unknown`，但仍推进 cursor，避免客户端被服务端新增 item 卡死。

**假设的 v1 线上映射：**

- `POST /api/v1/threads` → `thread.start`，返回 `ThreadStartResponse`。
- `POST /api/v1/threads/{threadId}/resume` → `thread.resume`，返回 `ThreadResumeResponse`。
- `POST /api/v1/threads/{threadId}/turns` → `turn.start`，返回 `TurnStartResponse`；request body 的 `input` 是用户文本，`context` 是 IDE 附加上下文，`model`/`thinking` 为可选覆盖。
- `GET /api/v1/threads/{threadId}/turns/{turnId}/events?after=<cursor>` → SSE，事件 envelope 的 `eventId`/`cursor`/`type`/`threadId`/`turnId` 使用 camelCase。
- `GET /api/v1/threads/{threadId}/stream?after=<cursor>` → WS；连接建立后 client 发送 `{ "type": "resume", "afterCursor": "..." }`，之后接收同样的 `StreamEvent` JSON；cancel 使用 `{ "type": "cancel", "turnId": "..." }` 或 REST interrupt。
- `POST /api/v1/threads/{threadId}/turns/{turnId}/cancel` → `turn.interrupt`，返回 `CancelTurnResponse`。

这些路径只允许出现在 `sdk/ts/src/client.ts`、`sdk/python/src/yanshi_sdk/client.py` 的一个 path adapter 中；D1 最终契约若不同，不得让 IDE 自己拼路径。

import {
  isValidEventId,
  isValidVersion,
  type StreamEvent,

import { ApiVersionError, HttpError, ProtocolError, StreamDisconnectedError } from "./errors.js";

export type FetchLike = (input: string | URL, init?: RequestInit) => Promise<Response>;
export type WebSocketFactory = (url: string, options?: { headers?: Record<string, string> }) => WebSocketLike;

export interface WebSocketLike {

export function makeUrl(baseUrl: string, path: string): string {
  return `${baseUrl.replace(/\/$/, "")}/${path.replace(/^\//, "")}`;

export function versionIsSupported(version: string | undefined, supported: readonly string[]): boolean {
  if (typeof version !== "string" || version.length === 0) return false;
  if (!isValidVersion(version)) return false;
  return supported.some((prefix) => version === prefix || version.startsWith(`${prefix}.`));
}

function headers(token?: string, accept = "application/json"): Headers {
  const out = new Headers({ Accept: accept });
  if (token) out.set("Authorization", `Bearer ${token}`);
  return out;
}

export async function requestJson<T>(
  options: TransportOptions,
  path: string,
  init: RequestInit,
): Promise<T> {
  const fetchImpl = options.fetch ?? fetch;
  const response = await fetchImpl(makeUrl(options.baseUrl, path), {
    ...init,
    headers: new Headers({ ...Object.fromEntries(headers(options.token)), ...(init.headers ?? {}) }),
  });
  const text = await response.text();
  let body: unknown = undefined;
  if (text) {
    try {
      body = JSON.parse(text);
    } catch (cause) {
      throw new ProtocolError(`non-JSON response from ${path}`, { cause });
    }
  }
  if (!response.ok) throw new HttpError(response.status, body);
  if (typeof body !== "object" || body === null) throw new ProtocolError(`response from ${path} is not a JSON object`);
  const version = response.headers.get("X-Yanshi-Api-Version") ??
    (typeof body === "object" && body !== null && "version" in body
      ? String((body as { version?: unknown }).version)
      : undefined);
  const supported = options.supportedVersions ?? ["v1"];
  if (!versionIsSupported(version, supported)) throw new ApiVersionError(version, supported);
  return body as T;
}

const KNOWN_EVENT_TYPES = new Set([
  "item.delta",
  "item.completed",
  "diff.updated",
  "turn.completed",
  "structured.result",
  "error",
  "unknown",
]);

function parseEvent(raw: string, eventName: string | undefined): StreamEvent {
  let value: unknown;
  try {
    value = JSON.parse(raw);
  } catch (cause) {
    throw new ProtocolError("invalid JSON event payload", { cause });
  }
  if (typeof value !== "object" || value === null) throw new ProtocolError("event payload is not an object");
  const event = value as Record<string, unknown>;
  if (!isValidVersion(typeof event.version === "string" ? event.version : undefined)) {
    throw new ProtocolError("event version is missing or invalid");
  }
  if (!isValidEventId(typeof event.eventId === "string" ? event.eventId : undefined)) {
    throw new ProtocolError("event eventId is missing or invalid");
  }
  if (!isValidCursor(typeof event.cursor === "string" ? event.cursor : undefined)) {
    throw new ProtocolError("event cursor is missing or invalid");
  }
  if (typeof event.threadId !== "string" || event.threadId.length === 0 ||
      typeof event.turnId !== "string" || event.turnId.length === 0) {
    throw new ProtocolError("event is missing threadId or turnId");
  }
  const declaredType = typeof event.type === "string" ? event.type : "";
  const resolvedType = KNOWN_EVENT_TYPES.has(declaredType) ? declaredType : "unknown";
  if (resolvedType === "unknown" && declaredType && eventName && !KNOWN_EVENT_TYPES.has(eventName)) {
    // keep the original `type` field untouched so callers see the server-declared type string,
    // but tag the normalized `type` as `unknown` for enum-typed consumers
  }
  return { ...event, type: resolvedType } as StreamEvent;
}

export async function* readSse(response: Response, supported: readonly string[]): AsyncGenerator<StreamEvent> {
  if (!response.ok) throw new HttpError(response.status, await response.text());
  if (!response.body) throw new StreamDisconnectedError(undefined);
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  let data: string[] = [];
  let eventName: string | undefined;
  let lastCursor: string | undefined;
  const flush = (): StreamEvent | undefined => {
    if (data.length === 0) { eventName = undefined; return undefined; }
    const event = parseEvent(data.join("\n"), eventName);
    data = [];
    eventName = undefined;
    if (!versionIsSupported(event.version, supported)) throw new ApiVersionError(event.version, supported);
    lastCursor = event.cursor;
    return event;
  };
  try {
    while (true) {
      const chunk = await reader.read();
      if (chunk.done) break;
      buffer += decoder.decode(chunk.value, { stream: true });
      const lines = buffer.split(/\r?\n/);
      buffer = lines.pop() ?? "";
      for (const line of lines) {
        if (line === "") {
          const event = flush();
          if (event) yield event;
        } else if (line.startsWith("event: ")) {
          eventName = line.slice(7);
        } else if (line.startsWith("data: ")) {
          data.push(line.slice(6));
        }
      }
    }
    const event = flush();
    if (event) yield event;
  } catch (cause) {
    if (cause instanceof ApiVersionError || cause instanceof ProtocolError) throw cause;
    throw new StreamDisconnectedError(lastCursor, { cause });
  } finally {
    reader.releaseLock();
  }
}

function socketOn(socket: WebSocketLike, name: string, listener: (...args: unknown[]) => void): void {
  if (socket.on) {
    socket.on(name, listener);
  } else if (socket.addEventListener) {
    socket.addEventListener(name, listener);
  } else {
    // unreachable for compliant WebSocketLike implementations; throw explicitly so tests catch it
    throw new ProtocolError(`socket does not support event subscription for ${name}`);
  }
}

export async function* readWebSocket(
  socket: WebSocketLike,
  afterCursor: string | undefined,
  supported: readonly string[],
  options: { turnId?: string; signal?: AbortSignal } = {},
): AsyncGenerator<StreamEvent> {
  const queue: StreamEvent[] = [];
  let wake: (() => void) | undefined;
  let closed: { code?: number; reason?: string } | undefined;
  let failure: unknown;
  const push = (event: StreamEvent): void => { queue.push(event); wake?.(); wake = undefined; };
  const messageListener = (...args: unknown[]): void => {
    const raw = args[0];
    const data = typeof raw === "object" && raw !== null && "data" in raw
      ? (raw as { data?: unknown }).data
      : raw;
    const text = typeof data === "string" ? data : new TextDecoder().decode(data as Uint8Array);
    try {
      const event = parseEvent(text, undefined);
      if (!versionIsSupported(event.version, supported)) throw new ApiVersionError(event.version, supported);
      push(event);
    } catch (cause) {
      failure = cause;
      wake?.();
      wake = undefined;
    }
  };
  const errorListener = (...args: unknown[]): void => {
    failure = args[0] ?? new ProtocolError("websocket error");
    wake?.();
    wake = undefined;
  };
  const closeListener = (...args: unknown[]): void => {
    const event = args[0];
    closed = (typeof event === "object" && event !== null && ("code" in event || "reason" in event))
      ? (event as { code?: number; reason?: string })
      : { code: 1006, reason: "closed" };
    wake?.();
    wake = undefined;
  };
  socketOn(socket, "message", messageListener);
  socketOn(socket, "error", errorListener);
  socketOn(socket, "close", closeListener);
  const open = new Promise<void>((resolve, reject) => {
    if (socket.readyState === OPEN) { resolve(); return; }
    socketOn(socket, "open", () => resolve());
    socketOn(socket, "error", (...args: unknown[]) => reject(args[0]));
  });
  await open;
  socket.send(JSON.stringify({ type: "resume", afterCursor: afterCursor ?? null }));
  let lastCursor = afterCursor;
  try {
    while (!closed || queue.length > 0) {
      if (options.signal?.aborted) return;
      if (failure) throw failure;
      if (queue.length === 0) await new Promise<void>((resolve) => { wake = resolve; });
      if (options.signal?.aborted) return;
      if (failure) throw failure;
      const event = queue.shift();
      if (event) {
        lastCursor = event.cursor;
        if (options.turnId && event.turnId !== options.turnId) continue;
        yield event;
      }
    }
    if (closed && closed.code !== 1000) throw new StreamDisconnectedError(lastCursor, { cause: closed.reason });
  } catch (cause) {
    if (cause instanceof ApiVersionError || cause instanceof ProtocolError || cause instanceof StreamDisconnectedError) throw cause;
    throw new StreamDisconnectedError(lastCursor, { cause });
  } finally {
    socket.close(1000, "client finished");
  }
}

import type {
  CancelTurnResponse,
  RunTurnRequest,
  StreamEvent,
  ThreadResumeResponse,
  ThreadStartRequest,
  ThreadStartResponse,
  TurnStartResponse,
} from "./generated.js";
import { ProtocolError } from "./errors.js";
import {
  defaultWebSocketFactory,
  makeUrl,
  readSse,
  readWebSocket,
  requestJson,
  type TransportOptions,
  type WebSocketFactory,
} from "./transport.js";

export interface AgentClientOptions extends TransportOptions {
  streamTransport?: "sse" | "ws";
}

export interface StreamOptions {
  afterCursor?: string;
  signal?: AbortSignal;
  transport?: "sse" | "ws";
}

export class AgentClient {
  private readonly options: AgentClientOptions;

  constructor(options: AgentClientOptions) {
    this.options = {
      ...options,
      baseUrl: options.baseUrl.replace(/\/$/, ""),
      supportedVersions: options.supportedVersions ?? ["v1"],
      streamTransport: options.streamTransport ?? "sse",
    };
  }

  async start(request: ThreadStartRequest = {}): Promise<ThreadStartResponse> {
    return requestJson<ThreadStartResponse>(this.options, "/api/v1/threads", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(request),
    });
  }

  async resume(threadId: string): Promise<ThreadResumeResponse> {
    return requestJson<ThreadResumeResponse>(this.options, `/api/v1/threads/${encodeURIComponent(threadId)}/resume`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: "{}",
    });
  }

  async run(threadId: string, request: RunTurnRequest): Promise<TurnStartResponse> {
    if (!request.input.trim()) throw new ProtocolError("turn input must not be empty");
    return requestJson<TurnStartResponse>(this.options, `/api/v1/threads/${encodeURIComponent(threadId)}/turns`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(request),
    });
  }

  async *stream(threadId: string, turnId: string, options: StreamOptions = {}): AsyncGenerator<StreamEvent> {
    const transport = options.transport ?? this.options.streamTransport;
    const encodedThread = encodeURIComponent(threadId);
    const encodedTurn = encodeURIComponent(turnId);
    const after = options.afterCursor ? `?after=${encodeURIComponent(options.afterCursor)}` : "";
    const supported = this.options.supportedVersions ?? ["v1"];
    if (transport === "ws") {
      const factory: WebSocketFactory = this.options.websocketFactory ?? defaultWebSocketFactory;
      const url = makeUrl(this.options.baseUrl, `/api/v1/threads/${encodedThread}/stream${after}`)
        .replace(/^http:/, "ws:")
        .replace(/^https:/, "wss:");
      const socket = factory(url, this.options.token ? { headers: { Authorization: `Bearer ${this.options.token}` } } : undefined);
      if (options.signal) {
        if (options.signal.aborted) socket.close(1000, "aborted");
        else options.signal.addEventListener("abort", () => socket.close(1000, "aborted"), { once: true });
      }
      yield* readWebSocket(socket, options.afterCursor, supported, { turnId, signal: options.signal });
      return;
    }
    const fetchImpl = this.options.fetch ?? fetch;
    const response = await fetchImpl(makeUrl(this.options.baseUrl, `/api/v1/threads/${encodedThread}/turns/${encodedTurn}/events${after}`), {
      method: "GET",
      signal: options.signal,
      headers: new Headers({
        Accept: "text/event-stream",
        ...(this.options.token ? { Authorization: `Bearer ${this.options.token}` } : {}),
      }),
    });
    for await (const event of readSse(response, supported)) {
      if (event.turnId !== turnId) continue;
      yield event;
    }
  }

  async cancel(threadId: string, turnId: string): Promise<CancelTurnResponse> {
    return requestJson<CancelTurnResponse>(this.options, `/api/v1/threads/${encodeURIComponent(threadId)}/turns/${encodeURIComponent(turnId)}/cancel`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: "{}",
    });
  }
}

    def __init__(self, received: str | None, supported: tuple[str, ...]) -> None:

    def __init__(self, status: int, body: object) -> None:
        message = body.get("message") if isinstance(body, dict) else None
        super().__init__(str(message or f"HTTP {status}"))
        self.status = status
        self.body = body

- [ ] **Step 1: 实现完整 async transport**

`_decode_json_response` 是版本校验的唯一入口；`request_json` 调用注入的 `httpx.AsyncClient.request` 后再走 `_decode_json_response`。Python 3.11+ 把 `asyncio.CancelledError` 移到 `BaseException`，所以所有 transport `except` 码必须先 re-raise 它，避免被 `StreamDisconnectedError` 吞掉。

```python
# sdk/python/src/yanshi_sdk/transport.py
from __future__ import annotations

import asyncio
import json
import re
from collections.abc import AsyncIterator, Callable
from typing import Any

import httpx
from websockets.asyncio.client import connect

from .errors import ApiVersionError, HttpError, ProtocolError, StreamDisconnectedError
from .generated import KNOWN_EVENT_TYPES, StreamEvent


def make_url(base_url: str, path: str) -> str:
    return f"{base_url.rstrip('/')}/{path.lstrip('/')}"


def version_supported(version: str | None, supported: tuple[str, ...]) -> bool:
    if not isinstance(version, str):
        return False
    match = re.fullmatch(r"v([0-9]+)(?:\.[0-9]+)?", version)
    if not match:
        return False
    major = match.group(1)
    return any(re.fullmatch(rf"v{re.escape(major)}", prefix) is not None for prefix in supported)


def normalize_event_type(value: object) -> str:
    text = str(value) if value is not None else ""
    return text if text in KNOWN_EVENT_TYPES else "unknown"


HttpFactory = Callable[[], httpx.AsyncClient]


class Transport:
    def __init__(
        self,
        base_url: str,
        token: str | None = None,
        supported: tuple[str, ...] = ("v1",),
        http_factory: HttpFactory | None = None,
    ) -> None:
        self.base_url = base_url.rstrip("/")
        self.token = token
        self.supported = supported
        self.http = http_factory() if http_factory else httpx.AsyncClient(timeout=None)

    def _headers(self, accept: str = "application/json") -> dict[str, str]:
        headers = {"Accept": accept}
        if self.token:
            headers["Authorization"] = f"Bearer {self.token}"
        return headers

    async def request_json(self, path: str, method: str, body: object | None = None) -> dict[str, Any]:
        response = await self.http.request(
            method,
            make_url(self.base_url, path),
            headers={**self._headers(), "Content-Type": "application/json"},
            content=json.dumps(body if body is not None else {}),
        )
        return await self._decode_json_response(path, response)

    async def _decode_json_response(self, path: str, response: httpx.Response) -> dict[str, Any]:
        try:
            value: Any = response.json()
        except ValueError as cause:
            raise ProtocolError(f"non-JSON response from {path}") from cause
        if response.status_code >= 400:
            raise HttpError(response.status_code, value)
        if not isinstance(value, dict):
            raise ProtocolError(f"JSON response from {path} is not an object")
        version = response.headers.get("X-Yanshi-Api-Version") or (str(value.get("version")) if value.get("version") else None)
        if not version_supported(version, self.supported):
            raise ApiVersionError(version, self.supported)
        return value

    async def sse(self, path: str, after_cursor: str | None = None) -> AsyncIterator[StreamEvent]:
        params = {"after": after_cursor} if after_cursor else None
        last_cursor = after_cursor
        try:
            async with self.http.stream("GET", make_url(self.base_url, path), params=params, headers=self._headers("text/event-stream")) as response:
                if response.status_code >= 400:
                    raise HttpError(response.status_code, await response.aread())
                event_name: str | None = None
                data: list[str] = []
                async for line in response.aiter_lines():
                    if line == "":
                        if not data:
                            event_name = None
                            continue
                        try:
                            raw: Any = json.loads("\n".join(data))
                        except json.JSONDecodeError as cause:
                            raise ProtocolError("invalid JSON SSE payload") from cause
                        if not isinstance(raw, dict):
                            raise ProtocolError("SSE payload is not an object")
                        if "type" not in raw and event_name:
                            raw["type"] = event_name
                        raw["type"] = normalize_event_type(raw.get("type"))
                        event = StreamEvent.model_validate(raw)
                        if not version_supported(event.version, self.supported):
                            raise ApiVersionError(event.version, self.supported)
                        last_cursor = event.cursor
                        yield event
                        data = []
                        event_name = None
                    elif line.startswith("event: "):
                        event_name = line[7:]
                    elif line.startswith("data: "):
                        data.append(line[6:])
        except asyncio.CancelledError:
            raise
        except (ApiVersionError, ProtocolError, HttpError):
            raise
        except Exception as cause:
            raise StreamDisconnectedError(last_cursor, cause) from cause

    async def websocket(self, path: str, after_cursor: str | None = None) -> AsyncIterator[StreamEvent]:
        ws_url = make_url(self.base_url, path).replace("http://", "ws://", 1).replace("https://", "wss://", 1)
        headers = self._headers()
        last_cursor = after_cursor
        try:
            async with connect(ws_url, additional_headers=headers) as socket:
                await socket.send(json.dumps({"type": "resume", "afterCursor": after_cursor}))
                async for raw in socket:
                    if isinstance(raw, bytes):
                        raw = raw.decode("utf-8")
                    try:
                        value: Any = json.loads(raw)
                    except json.JSONDecodeError as cause:
                        raise ProtocolError("invalid JSON WebSocket payload") from cause
                    if not isinstance(value, dict):
                        raise ProtocolError("WebSocket payload is not an object")
                    value["type"] = normalize_event_type(value.get("type"))
                    event = StreamEvent.model_validate(value)
                    if not version_supported(event.version, self.supported):
                        raise ApiVersionError(event.version, self.supported)
                    last_cursor = event.cursor
                    yield event
        except asyncio.CancelledError:
            raise
        except (ApiVersionError, ProtocolError, HttpError, StreamDisconnectedError):
            raise
        except Exception as cause:
            raise StreamDisconnectedError(last_cursor, cause) from cause

    async def close(self) -> None:
        await self.http.aclose()
```

# sdk/python/src/yanshi_sdk/client.py
from __future__ import annotations

from collections.abc import AsyncIterator
from dataclasses import dataclass
from urllib.parse import quote

from .generated import (
    CancelTurnResponse, RunTurnRequest, StreamEvent, ThreadResumeResponse,
    ThreadStartRequest, ThreadStartResponse, TurnStartResponse,
)
from .transport import Transport

@dataclass(frozen=True)
class StreamOptions:
    after_cursor: str | None = None
    transport: str = "sse"

class AgentClient:
    def __init__(
        self,
        base_url: str,
        token: str | None = None,
        *,
        stream_transport: str = "sse",
        supported_versions: tuple[str, ...] = ("v1",),
    ) -> None:
        if stream_transport not in {"sse", "ws"}:
            raise ValueError("stream_transport must be 'sse' or 'ws'")
        self.transport = Transport(base_url, token, supported_versions)
        self.stream_transport = stream_transport

    async def start(self, request: ThreadStartRequest | None = None) -> ThreadStartResponse:
        value = await self.transport.request_json(
            "/api/v1/threads", "POST", (request or ThreadStartRequest()).model_dump(by_alias=True, exclude_none=True)
        )
        return ThreadStartResponse.model_validate(value)

    async def resume(self, thread_id: str) -> ThreadResumeResponse:
        value = await self.transport.request_json(f"/api/v1/threads/{quote(thread_id, safe='')}/resume", "POST")
        return ThreadResumeResponse.model_validate(value)

    async def run(self, thread_id: str, request: RunTurnRequest) -> TurnStartResponse:
        if not request.input.strip():
            raise ValueError("turn input must not be empty")
        value = await self.transport.request_json(
            f"/api/v1/threads/{quote(thread_id, safe='')}/turns", "POST",
            request.model_dump(by_alias=True, exclude_none=True),
        )
        return TurnStartResponse.model_validate(value)

    async def stream(
        self, thread_id: str, turn_id: str, options: StreamOptions | None = None
    ) -> AsyncIterator[StreamEvent]:
        options = options or StreamOptions(transport=self.stream_transport)
        thread = quote(thread_id, safe="")
        turn = quote(turn_id, safe="")
        path = f"/api/v1/threads/{thread}/turns/{turn}/events"
        if options.transport == "ws":
            ws_path = f"/api/v1/threads/{thread}/stream"
            async for event in self.transport.websocket(ws_path, options.after_cursor):
                if event.turn_id == turn_id:
                    yield event
            return
        async for event in self.transport.sse(path, options.after_cursor):
            if event.turn_id == turn_id:
                yield event

    async def cancel(self, thread_id: str, turn_id: str) -> CancelTurnResponse:
        value = await self.transport.request_json(
            f"/api/v1/threads/{quote(thread_id, safe='')}/turns/{quote(turn_id, safe='')}/cancel", "POST"
        )
        return CancelTurnResponse.model_validate(value)

    async def aclose(self) -> None:
        await self.transport.close()

# sdk/python/tests/test_version_matrix.py
from __future__ import annotations

import json
from collections.abc import AsyncIterator

import httpx
import pytest

from yanshi_sdk import AgentClient
from yanshi_sdk.errors import ApiVersionError
from yanshi_sdk.transport import Transport


def _response(version: str | None, payload: dict) -> httpx.Response:
    headers = {"Content-Type": "application/json"}
    if version:
        headers["X-Yanshi-Api-Version"] = version
    return httpx.Response(200, headers=headers, content=json.dumps(payload))


def _build_client(version: str | None) -> tuple[AgentClient, httpx.MockTransport]:
    captured: list[httpx.Request] = []

    def handler(request: httpx.Request) -> httpx.Response:
        captured.append(request)
        body = {"thread": {"id": "thread-001", "status": "active", "createdAt": "2026-07-21T08:00:00Z", "updatedAt": "2026-07-21T08:00:00Z"}}
        if version:
            body["version"] = version
            body["futureField"] = True
        return _response(version, body)

    mock = httpx.MockTransport(handler)
    client = AgentClient("http://localhost")
    client.transport.http = httpx.AsyncClient(transport=mock)
    return client, mock


@pytest.mark.asyncio
async def test_minor_version_is_additive_through_public_client() -> None:
    client, mock = _build_client("v1.1")
    try:

// ide/vscode/src/budget.ts
import type { ContextItem, OpenFileContext, SelectionContext } from "@x6nux/yanshi-sdk";

export interface ContextLimits {
  maxOpenFiles: number;
  maxContextBytes: number;
}

export interface SelectionCandidate {
  path: string;
  content: string;
  range: { start: number; end: number };
}

export interface OpenFileCandidate {
  path: string;
  content: string;
}

export function truncateUtf8(value: string, maxBytes: number): { text: string; truncated: boolean } {
  if (maxBytes <= 0) return { text: "", truncated: value.length > 0 };
  if (Buffer.byteLength(value, "utf8") <= maxBytes) return { text: value, truncated: false };
  let end = value.length;
  while (end > 0 && Buffer.byteLength(value.slice(0, end), "utf8") > maxBytes) end -= 1;
  const text = value.slice(0, end);
  return { text, truncated: text !== value };
}

export function applyContextBudget(
  selection: SelectionCandidate | undefined,
  openFiles: readonly OpenFileCandidate[],
  limits: ContextLimits,
): ContextItem[] {
  const result: ContextItem[] = [];
  let remainingBytes = Math.max(0, limits.maxContextBytes);
  let remainingItems = Math.max(0, limits.maxOpenFiles) + 1;

  if (selection && remainingBytes > 0 && remainingItems > 0) {
    const bounded = truncateUtf8(selection.content, remainingBytes);
    const item: SelectionContext = {
      kind: "selection",
      path: selection.path,
      content: bounded.text,
      range: selection.range,
      truncated: bounded.truncated,
    };
    result.push(item);
    remainingBytes -= Buffer.byteLength(item.content, "utf8");
    remainingItems -= 1;
  }

  let openFileCount = 0;
  for (const candidate of openFiles) {
    if (remainingBytes <= 0 || remainingItems <= 0 || openFileCount >= limits.maxOpenFiles) break;
    const bounded = truncateUtf8(candidate.content, remainingBytes);
    const item: OpenFileContext = {
      kind: "openFile",
      path: candidate.path,
      content: bounded.text,
      truncated: bounded.truncated,
    };
    result.push(item);
    remainingBytes -= Buffer.byteLength(item.content, "utf8");
    remainingItems -= 1;
    openFileCount += 1;
  }
  return result;
}

export function collectContext(limits: ContextLimits, editor = vscode.window.activeTextEditor): ContextItem[] {

    ? {

    .map((document) => ({
      path: path.normalize(document.uri.fsPath),
      content: document.getText(),

import * as vscode from "vscode";
import type { StreamEvent } from "@x6nux/yanshi-sdk";

export class OutputRenderer {
  private terminal = false;

  constructor(readonly channel = vscode.window.createOutputChannel("Yanshi")) {}

  dispose(): void { this.channel.dispose(); }
  isTerminal(): boolean { return this.terminal; }

  begin(threadId: string, turnId: string): void {
    this.terminal = false;
    this.channel.appendLine(`[yanshi] thread=${threadId} turn=${turnId}`);
    this.channel.show(true);
  }

  consume(event: StreamEvent): void {
    switch (event.type) {
      case "item.delta":
        this.channel.append(event.delta?.text ?? "");
        break;
      case "item.completed":
        this.channel.appendLine("");
        break;
      case "diff.updated":
        this.channel.appendLine(`\n[diff] ${event.diff?.path ?? "<unknown>"}`);
        break;
      case "structured.result":
        this.channel.appendLine(`\n[result] ${event.structuredResult?.summary ?? (event.structuredResult?.ok ? "ok" : "failed")}`);
        break;
      case "error":
        this.channel.appendLine(`\n[error] ${event.error?.code ?? "unknown"}: ${event.error?.message ?? "unknown error"}`);
        break;
      case "turn.completed":
        this.terminal = true;
        this.channel.appendLine(`\n[done] ${event.turn?.status ?? "completed"}`);
        break;
      case "unknown":
        this.channel.appendLine(`\n[event] ignored unknown event at cursor ${event.cursor}`);
        break;
    }
  }

  markCancelled(): boolean {
    if (this.terminal) return false;
    this.terminal = true;
    this.channel.appendLine("\n[cancelled]");
    return true;
  }

  reconnecting(cursor: string | undefined, attempt: number): void {
    this.channel.appendLine(`\n[reconnecting] attempt=${attempt} cursor=${cursor ?? "<none>"}`);
  }

  reconnected(cursor: string | undefined): void {
    this.channel.appendLine(`\n[reconnected] cursor=${cursor ?? "<none>"}`);
  }

  fail(error: unknown): void {
    this.channel.appendLine(`\n[connection error] ${error instanceof Error ? error.message : String(error)}`);
  }
}

// ide/vscode/src/diff-model.ts
import type { FileChange } from "@x6nux/yanshi-sdk";

export interface OrderedChange {
  change: FileChange;
  cursor: string;
}

function compareCursor(left: string, right: string): number {
  const leftMatch = /^c-([0-9]+)$/.exec(left);
  const rightMatch = /^c-([0-9]+)$/.exec(right);
  if (leftMatch && rightMatch) {
    const a = BigInt(leftMatch[1]);
    const b = BigInt(rightMatch[1]);
    return a < b ? -1 : a > b ? 1 : 0;
  }
  return left.localeCompare(right);
}

export class DiffModel {
  private latestChange: OrderedChange | undefined;

  remember(change: FileChange, cursor: string): void {
    if (!this.latestChange || compareCursor(cursor, this.latestChange.cursor) >= 0) {
      this.latestChange = { change, cursor };
    }
  }

  latest(): OrderedChange | undefined {
    return this.latestChange;
  }
}

export function diffContents(change: FileChange): { before: string; after: string } {
  if (change.before !== undefined || change.after !== undefined) {
    return { before: change.before ?? "", after: change.after ?? "" };
  }
  if (change.unifiedDiff) {
    return { before: "", after: change.unifiedDiff };
  }
  return { before: "", after: `No diff content was supplied for ${change.path}` };
}

```ts
// ide/vscode/src/extension.ts
import * as vscode from "vscode";
import { AgentClient, type StreamEvent } from "@x6nux/yanshi-sdk";
import { clientOptions, readConfig, type ExtensionConfig } from "./config.js";
import { collectContext } from "./context.js";
import { DiffStore } from "./diff.js";
import { OutputRenderer } from "./output.js";

interface PersistedState { threadId?: string; cursor?: string; }

type ClientFactory = (config: ExtensionConfig) => AgentClient;

export class TurnController {
  private client: AgentClient | undefined;
  private active: { threadId: string; turnId: string; cancel: AbortController } | undefined;
  private state: PersistedState;

  constructor(
    private readonly context: vscode.ExtensionContext,
    private readonly output = new OutputRenderer(),
    private readonly diffs = new DiffStore(),
    private readonly clientFactory: ClientFactory = (config) => new AgentClient(clientOptions(config)),
  ) {
    this.state = context.workspaceState.get<PersistedState>("yanshi.state", {});
  }

  dispose(): void { this.output.dispose(); }

  async run(): Promise<void> {
    if (this.active) {
      void vscode.window.showInformationMessage("Yanshi: a turn is already running");
      return;
    }
    const editor = vscode.window.activeTextEditor;
    const prompt = await vscode.window.showInputBox({ prompt: "Send a turn to Yanshi", ignoreFocusOut: true });
    if (!prompt?.trim()) return;
    const config = await readConfig(this.context);
    this.client = this.clientFactory(config);
    let threadId = this.state.threadId;
    if (!threadId) {
      const started = await this.client.start({ cwd: vscode.workspace.workspaceFolders?.[0]?.uri.fsPath });
      threadId = started.thread.id;
      await this.save({ threadId, cursor: undefined });
    } else {
      await this.client.resume(threadId);
    }
    const turn = await this.client.run(threadId, {
      input: prompt,
      context: collectContext({ maxOpenFiles: config.maxOpenFiles, maxContextBytes: config.maxContextBytes }, editor),
    });
    const abort = new AbortController();
    this.active = { threadId, turnId: turn.turn.id, cancel: abort };
    this.output.begin(threadId, turn.turn.id);
    try {
      for await (const event of this.client.stream(threadId, turn.turn.id, {
        afterCursor: this.state.cursor,
        signal: abort.signal,
        transport: config.streamTransport,
      })) {
        await this.save({ threadId, cursor: event.cursor });
        this.consume(event);
        if (event.type === "turn.completed") return;
      }
    } catch (error) {
      if (!abort.signal.aborted) this.output.fail(error);
      throw error;
    } finally {
      this.active = undefined;
    }
  }

  async cancel(): Promise<void> {
    const active = this.active;
    if (!active || !this.client) {
      void vscode.window.showInformationMessage("Yanshi: no active turn");
      return;
    }
    if (!this.output.markCancelled()) return;
    active.cancel.abort();
    await this.client.cancel(active.threadId, active.turnId);
  }

  async showLastDiff(): Promise<void> { await this.diffs.show(); }

  private consume(event: StreamEvent): void {
    this.output.consume(event);
    if (event.type === "diff.updated" && event.diff) this.diffs.remember(event.diff, event.cursor);
  }

  private async save(state: PersistedState): Promise<void> {
    this.state = state;
    await this.context.workspaceState.update("yanshi.state", state);
  }
}

export function activate(context: vscode.ExtensionContext): void {
  const controller = new TurnController(context);
  context.subscriptions.push(
    vscode.commands.registerCommand("yanshi.run", () => controller.run()),
    vscode.commands.registerCommand("yanshi.cancel", () => controller.cancel()),
    vscode.commands.registerCommand("yanshi.showDiff", () => controller.showLastDiff()),
    { dispose: () => controller.dispose() },
  );
}

export function deactivate(): void {}
```

```ts
// ide/vscode/src/recovery.ts
import type { StreamEvent } from "@x6nux/yanshi-sdk";

export interface RecoveryHooks {
  stream(afterCursor: string | undefined): AsyncIterable<StreamEvent>;
  resume(): Promise<void>;
  consume(event: StreamEvent): Promise<void> | void;
  save(cursor: string): Promise<void>;
  sleep(ms: number): Promise<void>;
  onReconnecting?(cursor: string | undefined, attempt: number): void;
  onReconnected?(cursor: string | undefined): void;
  onError?(error: unknown): void;
  signal?: AbortSignal;
}

export async function runWithRecovery(
  hooks: RecoveryHooks,
  initialCursor?: string,
  maxAttempts = 5,
): Promise<string | undefined> {
  const seen = new Set<string>();
  let cursor = initialCursor;
  for (let attempt = 0; attempt < maxAttempts; attempt += 1) {
    if (hooks.signal?.aborted) return cursor;
    try {
      for await (const event of hooks.stream(cursor)) {
        if (hooks.signal?.aborted) return cursor;
        cursor = event.cursor;
        await hooks.save(cursor);
        if (seen.has(event.eventId)) continue;
        seen.add(event.eventId);
        await hooks.consume(event);
        if (event.type === "turn.completed") return cursor;
      }
      return cursor;
    } catch (error) {
      if (hooks.signal?.aborted) return cursor;
      hooks.onError?.(error);
      if (attempt === maxAttempts - 1) throw error;
      const nextAttempt = attempt + 1;
      hooks.onReconnecting?.(cursor, nextAttempt);
      if (hooks.signal?.aborted) return cursor;
      await hooks.sleep(Math.min(8000, 250 * 2 ** attempt));
      if (hooks.signal?.aborted) return cursor;
      await hooks.resume();
      if (hooks.signal?.aborted) return cursor;
      hooks.onReconnected?.(cursor);
    }
  }
  return cursor;
}
```

`seen` 在单次 recovery 生命周期内跨所有重连尝试保留；SDK transport 仍原样交付 duplicate。每个 event 先持久化 cursor，再去重/消费；sleep 前、sleep 后、resume 后都检查 abort，保证 sleep 期间 cancel 时 `resume()` 调用次数为 0。

## 待决策点

这些不是施工时可静默选择的细节，应在 D1 V14 contract review 中逐项定案；在定案前保留本计划的 provisional 标记。

1. **V14 传输形态：** resource REST + SSE/WS，还是 JSON-RPC over WS。当前 plan 采用 REST resource path，并把 path 集中在 adapter；若 D1 采用 RPC，不改变 SDK 上层方法签名。
2. **thread 生命周期命名：** `POST /threads`/`/resume`/`/turns`/`/cancel` 与 roadmap 的 `thread.start`/`thread.resume`/`turn.interrupt` 的最终映射。
3. **WS replay 语义：** WS 建连后是 `resume` client message，还是 query/header 直接携带 cursor；服务端是否 replay cursor 本身，必须用 eventId 去重规则固定。
4. **SSE 断线语义：** 使用 `after` query、`Last-Event-ID` header，还是两者均支持；本计划初版使用 `after`，D1 可在 transport 层增加 header adapter。
5. **版本字符串：** `v1`/`v1.1` 还是 semver `1.0`；客户端当前以 `v1` prefix 规则实现，最终只允许一个 canonical 解析函数。
6. **item vocabulary：** 是否保留 `agent_chunk`/`thinking`/`tool_call` 的语义，还是统一为 `item.delta`/`item.completed`；映射必须可从 `frame.go` 字段追溯，不能让 SDK 吞掉 reasoning、tool、structured result 或 diff。
7. **IDE 上下文信任标记：** V14 是否为 `selection`/`openFile` 增加 `source`/`trust`/`additionalContext` 包装；当前假设 server 将其作为非用户指令 context 处理。
8. **diff payload：** 服务端提供 `before`/`after`、unified diff，还是只给 path + diff。IDE 已支持三者中的 before/after 与 unifiedDiff 字段，但需要 D1 规定至少一个可靠字段。
9. **鉴权与本地发现：** SDK 是否需要复用 `internal/lockfile` 的发现协议，还是只接受显式 `serverUrl`；本计划默认显式 URL，VS Code 不读取 OS cache lockfile。
10. **生成工具归属：** D1 是否提交 canonical schema 和生成版本锁；若 D1 提供 generated TS，D2 必须改为消费其 artifact，不能维护两份生成类型。

- **D1/V14（硬依赖）：** 提供稳定的版本、schema、thread/turn/item 资源、start/resume/interrupt/run/stream 语义、SSE/WS cursor/backpressure、unknown field policy。D2 在 D1 未完成前只能使用本计划的 provisional fixture 做 client-first 开发。

## 风险与兜底

1. **D1 contract 漂移：** provisional path/event/schema 与 canonical V14 不一致时，立即停止 D2 发布；只修改 `sdk/schema/`、TS/Python path adapter 和 D1 server-side legacy adapter，不在 IDE 中散落新 path，也不让 SDK 直接消费 `internal/proto.ServerFrame`。
2. **版本或 identity 解析过松：** `v10`、`v1.`、空 version、空/非法 cursor、空/非法 eventId 一律 fail closed；若 D1 改 syntax，先更新 canonical schema、两语言 parser 和 matrix fixture，再解除 handoff gate。
3. **未来事件导致旧客户端停流：** transport 把 unknown type 归一为 `unknown`、保留 extra fields 并推进 cursor；若 payload 不能安全解析，只丢当前 turn 并返回 `ProtocolError`，禁止 silent loop。
4. **重连重复渲染或 cancel 后复活：** SDK 原样交付 duplicate；IDE `seen eventId` 去重。abort 在 stream/sleep/resume 前后检查；达到五次重试后停止自动恢复并把最后 cursor 留在 `workspaceState`，用户可重新执行 run/resume。
5. **selection/open files 泄露：** 一个 shared byte/item budget 约束全部 context；不记录内容，不上报 telemetry。超过预算时 UTF-8 安全截断；无法识别为 workspace file 的 document 不发送。
6. **token 泄露：** 非 loopback 只用 `Authorization: Bearer`，VS Code 优先 SecretStorage；不得放 URL、event、context、output、package metadata。若 SecretStorage 不可用，禁用远程连接并提示用户，不回退到 plaintext workspace file。
7. **diff payload 不完整：** `before/after` 优先；只有 `unifiedDiff` 时展示为只读 diff 文本；三者都缺失时显示明确占位，不写 workspace。out-of-order cursor 不能覆盖较新 diff。
8. **runtime test 加载 `vscode` 失败：** pure logic 放 `budget.ts`/`diff-model.ts`/`recovery.ts`；测试 UI/controller 时显式 `vi.mock("vscode", ...)`。如果 VS Code Electron smoke 环境不可用，unit gate 仍需通过，但不得发布 VSIX。
9. **Python cancellation 被包装：** `asyncio.CancelledError` 始终先 re-raise，其他 disconnect 才包装成 `StreamDisconnectedError`；取消传播测试是发布硬门禁。
10. **生成工具漂移：** 锁定 generator major/minor；生成结果 diff 必须 code review。若生成器无法保留 open event type 或 aliases，升级/配置模板，不手改生成物后跳过 generate gate。
